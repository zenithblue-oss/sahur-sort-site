# Sahur Sort site

Static site for Sahur Sort (landing, privacy policy, support). Hosted on GitHub Pages from `main`.

- Site icon: copied from the game repo `docs/storelisting/icon.png`. Re-copy it when the store icon changes.
- Screenshots: `img/shot-*.webp`, converted from the App Store iPhone set.
- Contact email: add it where `<!-- CONTACT_EMAIL -->` appears in `privacy.html` and `support.html`.
